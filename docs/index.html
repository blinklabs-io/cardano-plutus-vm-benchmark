Execution Model why categories matter
VMs differ in how they execute UPLC. A UPLC-level JIT compiler is doing fundamentally different work than a CEK interpreter, even when both happen to run on a JIT-compiled host runtime like JVM or .NET. Within-category numbers are like-for-like; cross-category numbers are not directly comparable.
VM Versions & Toolchain
Method
flat-decode + CEK evaluate on 89 Plutus scripts, except llvm-uplc, whose ranked time is steady-state execution after per-script JIT compilation. Scalus JIT and Chrysalis use three measurement samples; consult their raw framework output for uncertainty. Sequential execution, single Docker container. Geometric means within each category are computed only from scripts where every VM in that category produced a successful result.
